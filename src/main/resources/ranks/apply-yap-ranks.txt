# YaP first-party LuckPerms starter pack
# Applied via: ranks apply  |  dashboard Ranks tab  |  paste into console
# Docs: docs/PERMISSIONS.md
#
# Groups: default → vip → mod → admin (inheritance + track "yap")
# Weights / prefixes / suffixes for chat & tab list meta

lp creategroup default
lp creategroup vip
lp creategroup mod
lp creategroup admin

lp group default setweight 0
lp group vip setweight 10
lp group mod setweight 50
lp group admin setweight 100

lp group default meta set prefix "&7"
lp group vip meta set prefix "&a[VIP] "
lp group mod meta set prefix "&9[Mod] "
lp group admin meta set prefix "&c[Admin] "

lp group default meta set suffix ""
lp group vip meta set suffix " &a✦"
lp group mod meta set suffix ""
lp group admin meta set suffix ""

lp group vip parent set default
lp group mod parent set vip
lp group admin parent set mod

lp createtrack yap
lp track yap append default
lp track yap append vip
lp track yap append mod
lp track yap append admin
