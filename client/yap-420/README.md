# YaP 420 (optional Fabric client)

JE haze / particles for YaP420 consumables over plugin channel `yap:420`.

Vanilla JE and Bedrock still get potion effects from YaPItems — this mod is optional polish.

```bash
cd client/yap-420
./gradlew build
# → build/libs/yap-420-*.jar → .minecraft/mods/
```

Also included in `./scripts/packs/build-yap-client-render.sh` → `dist/client-mods/client_mods.zip`.
