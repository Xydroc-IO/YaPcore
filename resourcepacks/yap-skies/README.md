# YaP Skies

First-party sky overlay merged into `yapcore-default.zip`.

**Vanilla (every Java client):** high-res circular sun and moon, natural cloud banks,
richer overworld atmosphere (`sky` core shader), and a nebula End sky.

**Skybox loaders (optional client mod):** OptiFine-format day / sunrise / sunset /
night / storm / End layers under `assets/minecraft/optifine/sky/`. Works with
OptiFine, Skyboxify, Celestial, or Nuit + Interop.

Regenerate textures:

```bash
python3 scripts/generate-yap-skies.py
```
