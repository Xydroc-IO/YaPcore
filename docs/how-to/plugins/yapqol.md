# How to use YaPQoL (timber & excavator)

**Jar:** `via yap-items (`/yapqol`)`  
VIP timber axe (vein trees) and area excavator definitions.

## Players

Use the timber/excavator items from kits or shops as configured.

## Ops

```text
/yapqol
/yapitems give <timber_or_excavator_id>
```

Item defs ship with YaPItems / gameplay defaults.
