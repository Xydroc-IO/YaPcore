# How to use YaPFoliaBridge

**Jar:** `yap-folia-bridge.jar`  
Folia scheduling/view-distance diagnostics for operators.

## Commands

```text
/yapbridge
/yapviewdistance
```

Leave enabled on fleet instances; used for smoke/diagnostics.
