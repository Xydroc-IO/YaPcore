# How to use YaP420 (Blazed Boutique)

**Jar:** `yap-420.jar`  
Plant → grow → harvest → cure → pack → sell cannabis loop. Shop GUI title: **Blazed Boutique**.

## What it does

Gameplay plugin (GAMEPLAY tier). Items come from YaPItems (`yap420.yml`). Cash uses YaPPlayerData economy.

## Prerequisites

- `yap-420.jar` on the server where you sell (e.g. lobby NPC)
- `yap-items.jar` + `items/yap420.yml`
- Economy on
- Client pack with yap420 textures (else purple/black icons)

## Player loop

1. Get seeds — boutique buy, `/yap420 give` (admin), or craft later  
2. Right-click **farmland** (light + water nearby)  
3. Wait stages → harvest mature plant → **wet bud**  
4. Place **drying rack** → deposit wet → wait → collect **cured**  
5. Pack grams/oz/pounds (boutique buttons, packaging press, or `/yap420 pack`)  
6. Open Blazed Boutique → sell  

Wild plants: new overworld chunks when `wild.enabled: true` (not backfilled).

## Blazed Boutique

Open: `/yap420 sell` or NPC `/npc setplayer <id> yap420 sell`.

| UI area | Action |
|---------|--------|
| Top rows | Sell items you hold (click=1, shift=all of type) |
| Buy row | Seeds, paper, rack, press |
| Pack row | Pack sativa/indica gram / ounce / pound |
| Gold | Sell everything priced |
| Barrier | Close |

### Default prices (`market` in config)

**Sell:** cured/gram sativa `8` · indica `9` · ounce `280`/`315` (+25% vs loose grams) · pound `5600`/`6300` (+25% vs ounces) · joints/blunts/brownie/fiber priced. Packing pays — boutique pack buttons show the premium.  
**Buy:** seeds `12` · paper `4` · rack `80` · press `120`.

Edit `plugins/YaP420/config.yml` → `/yap420 reload`.

## Pack ladder

`1 cured ≡ 1g` · `28g = 1oz` · `16oz = 1 pound` (configurable).

| Unit | How |
|------|-----|
| Gram | Boutique / press / craft / `/yap420 pack gram` |
| Ounce / pound | Press or `/yap420 pack ounce\|pound` |

`/yap420 unpack` steps down.

## Commands

| Command | Perm | Purpose |
|---------|------|---------|
| `/yap420 info` | use | Look-at plot/rack |
| `/yap420 sell` | use | Boutique GUI |
| `/yap420 pack\|unpack …` | use | CLI pack |
| `/yap420 give <id> [n]` | admin | Give items |
| `/yap420 remove` | admin | Remove plot/rack |
| `/yap420 reload` | admin | Reload |

Staff: YaPAdmin → YaP420 · yap-staff · Bedrock forms.

## Wire lobby NPC

```text
/npc create blazed_boutique Blazed Boutique
/npc setplayer blazed_boutique yap420 sell
```

Jar must be on lobby. Restart after install.

## Troubleshoot

| Symptom | Fix |
|---------|-----|
| Command unknown | Jar missing on this backend |
| Purple icons | Rebuild/sync pack SHA1; reconnect |
| Nothing to sell | Need cured/grams/etc. in inventory — not wet buds/seeds |
| No money | Economy off in PlayerData |
