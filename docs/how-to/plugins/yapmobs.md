# How to use YaPMobs (stacker + leveled)

**Jar:** `yap-stacker.jar / leveled-mobs`  
PDC mob/item/spawner stacking and distance-based mob levels.

## Ops

```text
/yapstacker
/yaplevel
```

Tune stack limits and level curves in plugin configs. Install via `gradle installGameplayDefaults`.
