# How to use YaPDiscord

**Jar:** `yap-discord.jar`  
Discord bridge for chat/alerts (configure bot token carefully).

## Ops

1. Put bot token in config/secrets (see SECRETS.md)
2. Set channel IDs
3. `/yapdiscord` or `/discord` for status/reload
