# How to use YaPHolo

**Jar:** `yap-holo.jar`  
Client-side packet holograms: text lines, items, pages, clicks, PlaceholderAPI.

## Quick start

```text
/yapholo
```

1. Create a hologram at your location  
2. Add lines (`&` color codes)  
3. Optional: PAPI placeholders like `%player_name%`  
4. Optional: click action → command / warp / server  
5. Save  

## Ideas

| Use | Tip |
|-----|-----|
| Spawn rules | Multi-line + pages |
| Server list | Click → `/server survival` or portal |
| Stats | PAPI + YaPSkills placeholders if available |
| Shop labels | Place above NPC / chest shop |

## Ops tips

- Holos are packets — no armor stands cluttering the world  
- If lines show raw `%…%`, install/enable PlaceholderAPI  
- After major pack/version changes, `/yapholo` reload if available
