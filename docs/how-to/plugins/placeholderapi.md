# How to use PlaceholderAPI

**Jar:** `yap-placeholderapi.jar`  
Clip-compatible PlaceholderAPI (plugin name `PlaceholderAPI`) for chat, tab, holos.

## Ops

```text
/papi list
/papi parse me %player_name%
```

Other YaP plugins expand `%…%` where configured.
