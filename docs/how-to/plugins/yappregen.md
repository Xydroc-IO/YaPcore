# How to use YaPPregen

**Jar:** `yap-pregen.jar`  
Chunk pre-generator so players do not hitch on first exploration.

## Workflow

```text
/yappregen
/yappregen status
```

Run on new worlds **before** opening to players. Watch MSPT while running; pause if the server struggles.
