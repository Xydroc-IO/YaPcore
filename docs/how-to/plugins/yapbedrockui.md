# How to use YaPBedrockUI

**Jar:** `yap-bedrock-ui.jar`  
Bedrock form UI bridge for menus (PlayerData hub, admin tools).

## Notes

When present, Floodgate/Bedrock players get forms for `/menu`, kits, homes, warps instead of only chest GUIs. Soft-dep — JE unchanged without it.
