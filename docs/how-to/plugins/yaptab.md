# How to use YaPTab

**Jar:** `yap-tab.jar`  
Tab list and nametag formatting (works with YaPPerms prefixes + PAPI).

## Ops

Edit `plugins/YaPTab/config.yml` header/footer/nametag patterns.

```text
/yaptab reload
```

Use PlaceholderAPI placeholders where supported.
