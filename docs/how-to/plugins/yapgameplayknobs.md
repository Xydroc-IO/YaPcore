# How to use YaPGameplayKnobs

**Jar:** `yap-gameplay-knobs.jar`  
Purpur-inspired encyclopedia of gameplay toggles (master switch off until you want them).

## Ops

```yaml
# knobs config
settings:
  enabled: false   # flip true when ready
```

```text
/yapknobs
```

Some crop/fluid hooks need YaP-Folia patch 0025.
