# YaP420

Folia-safe **plant → grow → harvest → dry/cure → craft → consume** loop for YaPcore.
Inspired by classic cannabis-farming mods; implemented first-party (no Forge/Fabric mod jars on the server).

## Install

```bash
gradle :yap420-plugin:installIntoPlugins
# or
gradle installGameplayDefaults
```

Jar: `plugins/yap-420.jar`. Soft-depends on **YaPItems** (catalog + recipes) and **YaPSkills** (optional herbalism XP).

Not seeded into every fleet instance by default — drop the jar or install gameplay defaults.

Item defs ship as `items/yap420.yml` (CMD **12200–12231**). Rebuild the client pack:

```bash
./scripts/packs/build-default-resourcepack.sh
```

Optional JE haze client: `client/yap-420` → channel `yap:420`.

## Thread map

| Work | Lane |
|------|------|
| Plant / harvest / rack interact / display spawn | SYNC region of block |
| Growth + cure progress checks | Global timer → SYNC hop per plot/rack |
| plots.yml / racks.yml | HEAVY (`YapSched.async`) |
| Haze plugin message | Entity scheduler after consume |

Never use `Bukkit.getScheduler()`. Domain `.java` files stay ≤500 lines (`gradle checkDomainLineLimits`).

## Loop

1. `/yap420 give yap420_seed_sativa` (or craft later) → right-click **farmland**
2. Wait for stages (light + water nearby) → harvest mature plant → wet bud
3. Place drying rack → deposit wet buds → wait → collect cured buds
4. Craft joint / blunt / brownie (YaPItems recipes — crafting table or crafter) → eat → potions (+ haze if Fabric client)
5. Pack retail units → `/yap420 sell` (or NPC `player:yap420 sell`) → cash via YaPPlayerData

Craft recipes register on base materials and validate YaP item ids (ExactChoice broke tables/autocrafters).
After `/yapitems reload` or join, recipes unlock in the recipe book. Ounces and pounds use the **packaging press** (or `/yap420 pack`) — not the crafting table.

## Pack & dealer

Ladder (configurable): **1 cured bud ≡ 1g** · **28g = 1 ounce** · **16 oz = 1 pound**.

| Unit | Item ids | How |
|------|----------|-----|
| Gram | `yap420_gram_*` | Craft 1 cured → 1g, packaging press, or `/yap420 pack gram` |
| Ounce | `yap420_ounce_*` | **Packaging press** (28g) — too many slots for a crafting table |
| Pound | `yap420_brick_*` | **Packaging press** (16 ounces) |

**Packaging press** (`yap420_packaging_press`): craft with iron + piston + chest, place, right-click for pack GUI (or hold cured/grams/ounces to quick-press). Punch to pick up. `/yap420 unpack` / press GUI unpacks one step.

**Sellable** (defaults in `market.sell`): cured, grams, ounces, pounds, joints, blunts, brownie, hemp fiber.  
**Buyable** (`market.buy`): seeds, rolling paper, drying rack, packaging press.

Economy requires **YaPPlayerData** with economy enabled. Wire a hub NPC with action `player:yap420 sell`.

## Wild plants

With `wild.enabled: true` (default), newly generated overworld chunks can spawn sparse plants on grass/dirt
(flower/tree style). Nether/end are skipped. Already-explored terrain is **not** backfilled — explore new
chunks (or regenerate) to find wild patches. Wild plots grow without irrigation; farm plots still need water.
Tune density via `chance-per-chunk` / `max-per-chunk` in `plugins/YaP420/config.yml`.
