Place optional island starter schematics here (e.g. island.schem / island.yschem).

When YaPWorld is installed, YaPblock will try to paste the schematic named in
config.yml (schematic.name). If the file is missing or YaPWorld is absent,
IslandStarterPack builds the classic starter island instead:

  Blocks: ~27 grass, ~51 dirt, 3 sand, 1 bedrock (bottom center), 1 oak tree
  Chest:  water bucket, lava bucket, ice×2, sugar cane, melon slice,
          pumpkin seeds, cactus, string×12, bone, red + brown mushroom
